# Assets Directory

This directory contains all game assets for Scoundrel.

## Structure

- **sfx/**: Sound effects directory
- **music/**: Background music directory
- **backgrounds/**: Background images directory
- **cards/**: Card images directory

## Adding Assets

Place your asset files in the appropriate subdirectory:
- Sound effects (.wav, .ogg) go in sfx/
- Music files (.mp3, .ogg) go in music/
- Background images (.png, .jpg) go in backgrounds/
- Card images (.png) go in cards/
